# BrainByte — SIH26003

**Team:** MEMORA  
**Problem Statement:** AI-Based Cognitive Gaming and Memory Assistance Platform for Elderly Dementia Patients

BrainByte is an elderly-friendly Android prototype for cognitive engagement, memory assistance, adaptive activities, voice guidance, reminders, calming exercises and caregiver insights.

## Prototype features

- Animated BrainByte splash screen
- English / Telugu / Hindi language-selection demo
- Simple first-time profile setup
- Elderly-friendly home with large controls
- Functional Object Recall game
- Adaptive difficulty based on activity performance
- Cognitive game hub: Memory Match, Object Recall, Sequence Recall, Pattern Recognition and Daily Recall
- Voice-guidance prototype using Android Text-to-Speech
- 5-4-3-2-1 grounding activity
- Daily reminder screen
- Caregiver engagement dashboard
- Lightweight native Android UI suitable for offline core activities
- Safety messaging: activity scores are for personalization, not diagnosis

## Adaptive loop

`PLAY → MEASURE → ANALYZE → ADAPT → RECOMMEND`

The current prototype uses deterministic rules so the adaptation is transparent and easy to demonstrate. More advanced personalization can be added after appropriate longitudinal testing and validation.

## Important

BrainByte supports cognitive engagement and memory assistance. It does not diagnose, cure or treat dementia and does not replace qualified medical care.
